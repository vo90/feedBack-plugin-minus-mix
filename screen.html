How the audio is made

For a normal single-stem source, this optional plugin connects directly to the managed local server you started from Stem Splitter and downloads the selected audio into a temporary workspace. Remote/custom servers, Docker sidecars and Stem Splitter's in-app engines are not supported yet. MinusMix subtracts that temporary stem from the original full mix, encodes once to Ogg Vorbis, and deletes the whole temporary separation. It never adds those stems to your original package.

If the source already contains the selected stem, MinusMix reuses it and skips the server. Charts, lyrics, artwork and metadata are copied into a new FeedPak containing only the rendered full mix.

Batch mode runs one GPU separation at a time for stability and reuses byte-identical audio separated earlier in that batch. Engines that support a persistent model can keep it warm between songs. The temporary reuse cache is deleted when the queue finishes.

AI separation is not mathematically perfect: faint bleed can remain, and sounds incorrectly placed in an excluded stem can also be reduced.
